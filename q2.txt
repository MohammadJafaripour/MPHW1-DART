جعبهٔ خالی، برچسب صفر

محدودیت زمان: ۱ ثانیه

محدودیت حافظه: ۲۵۶ مگابایت

صورت سؤال
در غرفهٔ سوغاتی یک نمایشگاه، بعضی جعبه‌ها نام هدیه‌ها را نگه می‌دارند و بعضی شمارهٔ برچسب‌ها را. مسئول غرفه فقط می‌خواهد اولین عضو هر جعبه را ببیند. ممکن است جعبه‌ای خالی باشد؛ اما عدد 0 و رشتهٔ Empty، اگر واقعاً داخل جعبه باشند، عضو معتبر محسوب می‌شوند.

به‌جای نوشتن روش‌های جداگانه برای جعبهٔ رشته‌ای و عددی، این دو ساختار را پیاده‌سازی کنید:


extension ListX<T> on List<T> {

  T? firstOrNull() {

    // پیاده‌سازی این بخش با شماست.

  }

}
Dart
و کلاس جنریک GiftBox<T> با فیلد final List<T> items و متد T? firstGift().

متد firstGift() باید از firstOrNull() استفاده کند. اگر جعبه خالی بود null برگرداند و در غیر این صورت اولین عضو را، بدون تغییر دادن فهرست، برگرداند.

ورودی
ورودی، یک List<T> است که به سازندهٔ GiftBox<T> داده می‌شود. نوع T می‌تواند String یا int باشد. فهرست می‌تواند خالی باشد.

خروجی
مقدار برگشتی firstGift() از نوع T? است.

مثال
نمونهٔ ۱

final box = GiftBox<int>([0, 7, 12]);

print(box.firstGift());
Dart

0
Plain text
نمونهٔ ۲

final box = GiftBox<String>([]);

print(box.firstGift());
Dart

null
Plain text
نمونهٔ ۳

final box = GiftBox<String>(['Empty', 'Mug']);

print(box.firstGift());
Dart

Empty
Plain text
نکات
در پیاده‌سازی Extension از isEmpty و first استفاده کنید.

در کنار firstOrNull() و firstGift()، با کامنت‌های کوتاه و روشن دلیل nullable بودن خروجی، تفاوت فهرست خالی با فهرستی که اولین عضو آن 0 یا Empty است و نقش جنریک بودن کلاس و Extension را توضیح دهید. تمرکز توضیحات بر تصمیم‌های اصلی پیاده‌سازی باشد.
