نامه‌ای که هست، نویسنده‌ای که نیست

محدودیت زمان: ۲ ثانیه

محدودیت حافظه: ۲۵۶ مگابایت

صورت سؤال
در نمایشگاهی به نام «کپسول زمان»، نامه‌هایی برای آینده نگهداری می‌شوند. نام نویسندهٔ بعضی نامه‌ها مشخص نیست؛ اما این موضوع به معنی نبودن خود نامه نیست. از طرفی ممکن است آرشیو هیچ نامه‌ای نداشته باشد.

برنامه‌ای بنویسید که اولین نامهٔ آرشیو را پیدا کند و بین «نامه‌ای با نویسندهٔ نامشخص» و «آرشیو خالی» تفاوت بگذارد.

برنامه باید شامل ساختارهای زیر باشد:

۱. کلاس Letter

این کلاس دو فیلد داشته باشد:

final int id;
final String? sender;
Dart
سازندهٔ کلاس، هر دو فیلد را با پارامترهای نام‌دار required دریافت کند. همچنین متد زیر را پیاده‌سازی کنید:

String displaySender()
Dart
این متد، اگر sender برابر null بود، رشتهٔ Guest و در غیر این صورت نام نویسنده را بدون تغییر برگرداند.

۲. کلاس جنریک Result<T>

این کلاس باید دارای دو فیلد و دو سازندهٔ زیر باشد:

final T? data;
final String? error;

Result.success(this.data) : error = null;
Result.failure(this.error) : data = null;
Dart
۳. کلاس انتزاعی Repository<T>

abstract class Repository<T> {
  Future<List<T>> getAll();
}
Dart
۴. کلاس LetterRepository

این کلاس باید Repository<Letter> را پیاده‌سازی کند و نامه‌ها را در فیلد زیر نگه دارد:

final List<Letter> letters;
Dart
سازندهٔ کلاس، این فیلد را با پارامتر نام‌دار required دریافت کند. همچنین متدهای زیر را داشته باشد:

Future<List<Letter>> getAll() که فهرست نامه‌ها را به‌صورت غیرهمگام برگرداند.
Future<Result<Letter>> firstLetter() که ابتدا با await نتیجهٔ getAll() را دریافت کند و سپس:
اگر فهرست خالی بود، Result<Letter>.failure('Archive Empty') برگرداند.
اگر فهرست خالی نبود، اولین نامه را با Result<Letter>.success(...) برگرداند؛ حتی اگر نویسندهٔ آن null باشد.
برای انتخاب اولین نامه از isEmpty و first استفاده کنید. متدهای کلاس‌ها فقط مقدار مناسب را برگردانند و هیچ‌کدام عملیات چاپ انجام ندهند.

ورودی
ورودی مسئله یک List<Letter> است که با سازنده به LetterRepository داده می‌شود. این فهرست ممکن است خالی باشد. شناسهٔ هر نامه عددی صحیح است و نویسندهٔ آن می‌تواند null باشد.

خروجی
متد firstLetter() مقداری از نوع Future<Result<Letter>> برمی‌گرداند:

اگر نامه‌ای وجود داشته باشد، فیلد data شامل اولین نامه و فیلد error برابر null است.
اگر آرشیو خالی باشد، فیلد data برابر null و فیلد error برابر Archive Empty است.
متد displaySender() نیز نام نویسنده یا مقدار پیش‌فرض Guest را برمی‌گرداند.

مثال
نمونهٔ ۱
void main() async {
  final repository = LetterRepository(letters: [
    Letter(id: 10, sender: null),
    Letter(id: 20, sender: 'Sara'),
  ]);

  final result = await repository.firstLetter();

  print(result.data?.displaySender() ?? result.error);
}

نکات
در کنار متدهای displaySender()، getAll() و firstLetter()، با کامنت‌های کوتاه و روشن منطق بخش‌های مهم پیاده‌سازی را توضیح دهید؛ از جمله مدیریت مقدار null، تفاوت موجود بودن نامه با مشخص بودن نویسنده، دلیل استفاده از Future و await، انتخاب حالت موفقیت یا خطا در Result<Letter> و مسئولیت هر کلاس.

کامنت‌ها باید دلیل تصمیم‌های اصلی را روشن کنند و صرفاً تکرار دستورات کد نباشند.
