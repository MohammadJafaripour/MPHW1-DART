# شماره‌هایی که یکی‌یکی اعلام می‌شوند

محدودیت زمان: ۲ ثانیه

محدودیت حافظه: ۲۵۶ مگابایت

## صورت سؤال

در یک جشنواره، شماره‌های نوبت از یک عدد مشخص شروع می‌شوند. مسئول سالن نمی‌خواهد همهٔ شماره‌ها را یک‌جا تحویل بگیرد؛ هر شماره باید به‌ترتیب و به‌عنوان یک پیام مستقل اعلام شود.

کلاس `QueueBoard` را با دو فیلد زیر بسازید:

```dart
final int start;
final int count;
```

این کلاس باید دو متد داشته باشد:

```dart
Future<int> loadStart()
Stream<int> announcements()
```

در `loadStart()` ابتدا با `await Future.delayed(Duration(seconds: 0))` یک دریافت غیرهمگام را شبیه‌سازی کنید و سپس `start` را برگردانید.

متد `announcements()` باید با `async*` نوشته شود. ابتدا شمارهٔ شروع را با `await loadStart()` دریافت کند؛ سپس با یک حلقه، دقیقاً `count` شمارهٔ پیاپی از `start` را با `yield` منتشر کند. پیش از هر `yield` نیز از `await Future.delayed(Duration(seconds: 0))` استفاده کنید.

اگر `count` صفر باشد، هیچ رویدادی منتشر نمی‌شود.

## ورودی

دو عدد صحیح `start` و `count` در سازندهٔ `QueueBoard` قرار می‌گیرند:

```text
0 ≤ start ≤ 1000
0 ≤ count ≤ 100
```

## خروجی

خروجی `announcements()` یک `Stream<int>` است. ترتیب اعداد منتشرشده باید از `start` آغاز شود و با هر رویداد یک واحد افزایش یابد.

## مثال

### نمونهٔ ۱

فراخوانی:

```dart
QueueBoard(start: 20, count: 3).announcements()
```

رویدادهای منتشرشده، به‌ترتیب:

```text
20
21
22
```

### نمونهٔ ۲

فراخوانی:

```dart
QueueBoard(start: 7, count: 0).announcements()
```

هیچ رویدادی منتشر نمی‌شود.

## نکات

ترتیب انتشار شماره‌ها باید حفظ شود و هیچ شماره‌ای اضافه‌تر از `count` تولید نشود.

در کنار `loadStart()` و `announcements()`، با کامنت‌های روشن نقش `Future` و `await` در دریافت مقدار آغازین، تفاوت نتیجهٔ تک‌مقداری با جریان چندمقداری، کاربرد `async*` و `yield` و رفتار جریان برای `count` برابر صفر را توضیح دهید.
