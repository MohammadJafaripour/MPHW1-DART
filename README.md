## اجرا

کافیه Dart SDK با پشتیبانی از null safety نصب باشه و دستور `dart` توی PATH قرار داشته باشه. از پوشهٔ اصلی پروژه، هر فایل رو جدا اجرا کن:

```powershell
dart Q1.dart
dart Q2.dart
dart Q3.dart
dart Q4.dart
dart Q5.dart
```

داخل `main()` هر فایل، آخرین نمونهٔ همون صورت سؤال قرار گرفته:

| فایل | خروجی نمونه |
| --- | --- |
| `Q1.dart` | `GUEST` |
| `Q2.dart` | `Empty` |
| `Q3.dart` | دو خط `Untitled` |
| `Q4.dart` | بدون خروجی، چون `count` صفره |
| `Q5.dart` | `Guest` |

برای بررسی خطاهای کد هم می‌تونی این دستور رو اجرا کنی:

```powershell
dart analyze Q1.dart Q2.dart Q3.dart Q4.dart Q5.dart
```

## تحویل در کوئرا

هر سؤال باید جداگانه و به شکل ZIP تحویل داده بشه. داخل هر ZIP فقط فایل `Qi.dart` مربوط به همون سؤال قرار می‌گیره؛ مثلاً `Q1.zip` فقط شامل `Q1.dart` می‌شه.

برای ساختن یا به‌روز کردن هر پنج ZIP توی PowerShell:

```powershell
foreach ($i in 1..5) {
    Compress-Archive -LiteralPath "Q$i.dart" -DestinationPath "Q$i.zip" -Force
}
```

ZIPها فایل تحویل هستن و توی گیت ثبت نمی‌شن. مهلت ارسال با تأخیر طبق راهنمای تمرین، ۱۰ روز پس از اتمام زمانه.
